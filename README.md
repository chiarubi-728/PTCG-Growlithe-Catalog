# 卡蒂狗・風速狗｜圖鑑核對

[開啟核對網頁](https://chiarubi-728.github.io/PTCG-Growlithe-Catalog/)

這是獨立的卡牌資料核對頁，不是收藏 App。只包含公開來源的卡牌資訊及卡圖，不包含個人收藏、拍照或 App 程式碼。

目前整理 200 筆來源紀錄：日文 67、繁中 50、英文 83，依插畫分成 75 組。排除 Pokémon TCG Pocket。這是現有資料的核對批次，**不代表全市場版本已收齊**。

## 使用方式

- 可依同圖分組、系列／卡號、卡號、卡名及底部年份排列。
- 可篩選語言、寶可夢及年份確認狀態，搜尋卡名、系列、卡號與繪師。
- 點卡圖或「看圖／底部放大」可查看完整卡圖與底部裁切。
- 「來源」連結可回到對應的日本官方、繁中官方或 TCG Collector 頁面。

同圖分組只表示插畫對應，沒有把不同語言、再版、卡號或加工版本合併成同一張卡。同卡號也不一定同圖。

## 年份注意事項

卡片底部版權年份和系列發售年份分開記錄。底部年份目前 10 筆目視確認、57 筆 OCR 待確認、133 筆尚未讀出；OCR 候選可能誤讀，請勿當成已核實資訊。多年份或未知值不以發售年補足。

## 圖片及離線使用

200 張卡圖與網頁一起存放於此儲存庫；網頁載入圖片不依賴原來源圖床。下載完整儲存庫後，保留 `index.html`、`review.css`、`review.js` 及 `images/` 的相對位置，即可在本機開啟核對頁。

卡圖與寶可夢相關內容權利屬各自權利人；公開來源不等於開放授權。本頁為非官方資料核對工具，不宣稱擁有卡圖著作權。
